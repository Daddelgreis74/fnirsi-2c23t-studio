Open Source OS

OpenScope v2026.10.1

Das vollständige modulare Open-Source Betriebssystem für den 2C23T (HW 4.0).

  • FFT-Spektrumanalysator & True RMS
  • Arbitrary Waveform Generator (CSV Wellen)
  • Bootloader Export & Runtime USB

So funktioniert der Bootloader-Flash-Vorgang:

  1. Schalte deinen FNIRSI 2C23T aus.
  2. Halte die Taste MENU gedrückt und drücke kurz Power, bis im Display BootLoader steht.
  3. Verbinde das Gerät per USB mit dem PC – das Laufwerk FNIRSI IAP erscheint.
  4. Klicke oben auf die gewünschte Firmware – die Studio-App überträgt die Datei in sicheren 4KB-Blöcken.
